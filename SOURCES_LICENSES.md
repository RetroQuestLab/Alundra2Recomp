# Sources and licenses

## Repository code and documentation

All source code and documentation in this repository is published under **GPL-3.0**.
See `LICENSE`.

## Assets not included

The following are not distributed in this repository:

- sprites, maps, fonts, dialogue windows, music and sound effects from the Alundra games;
- reference images, videos and working captures;
- PS1 data blobs generated from those assets;
- executables, libraries, BIOS files, BIN/CUE and ISO images.

These files must be supplied locally by anyone who has the rights to use them. They remain the
property of their respective owners.

Screenshots published in `docs/screenshots/` are captures of this remake's own renderer; they
contain no original game assets shipped as files.

## External dependencies

| PSn00bSDK 0.24 | PlayStation 1 toolchain | See the SDK license |
| OpenBIOS | Open-source BIOS for emulation | See the project license |

None of these dependencies are copied into the repository.

## Local generation

The PS1 font blob and the zone blobs are generated by the scripts in `tools/` from local,
untracked assets. The generation commands are documented in `README.md` and `CONTRIBUTING.md`.
